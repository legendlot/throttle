Production Runs is where you plan and submit a build. Each run becomes a consolidated parts pick list that the store issues against. Open it to create a run (fresh or repair), check a run’s status, confirm what the floor received, or manage an outsourced-vendor run.

Creating a run

  1. + New Run. Choose In-House or Outsourced (outsourced needs a vendor), pick the product, run date (defaults to tomorrow), line and shift.
  2. Add variants and quantities. For each variant set the E-Comm and Retail quantities; pick a colour where the variant has colour options (this is required).
  3. Create Run. The run is created and submitted to the store in one step. If an open run for that product already exists you will be asked whether to create another anyway.

A + Repair Run works similarly but creates a Planned run with no parts issue: operators scan units at the repair station instead. Click View on any run to open its detail: the consolidated pick list (grouped by category and part type, with shortfalls flagged), the work orders inside it, and the buttons to cancel, reject, confirm receipt, mark complete, or run the outsourced send-out and return steps.

⚠ Fresh runs submit immediately

There is no separate “submit” click: creating a fresh run sends it straight to the store. The run date defaults to tomorrow, not today, and colour is mandatory whenever the variant offers colour options. Confirming receipt with shortfalls automatically raises a Short Supply work order so the store re-issues the gap.

Outsourced runs (two-phase)

An outsourced run sends raw materials to a vendor who builds and returns the units. New outsourced runs split into a build half (done outside) and a finish half (done in-house), so only the parts the vendor needs go out and the packaging stays in until the units return. The run detail (View) carries the buttons for each step:

BUILD    Store issues the build pick (Car / Remote / Fastener only)
         -> Send to Vendor (run goes In Progress)

RECEIVE  Vendor returns units (instalments OK)
         -> Receive built units (count) into the pool        [run detail]

FINISH   -> Issue Finish Parts (packaging / accessories / battery / sticker)
         -> sticker each unit at Ext Inwarding (scanner) -> QC -> PKG Out

The pick list for a new outsourced run shows the build parts only, so the store issues just those; the finish parts are issued later with Issue Finish Parts, once the units are back. Use Receive built units on the run detail to count returns into the pool as they arrive. Outsourced runs created before this change keep their original one-step receive (assign a line, scan each unit at Ext Inwarding).

ⓘ Requests now start in Redline

Production raises every run, including outsourced and repair, from Redline’s New Run / Request screen. This Garage screen still shows and manages the runs, and is where the outsourced send-out, receive and finish steps live.
