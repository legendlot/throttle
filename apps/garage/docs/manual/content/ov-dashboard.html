The Dashboard is Garage’s morning overview. It shows the day’s key numbers, what needs reordering, what each product can still be built into, and recent inward, production and returns activity. Open it first thing to see the state of the operation at a glance. It refreshes itself every minute.

The panels

Below the cards, the Dashboard lays out the working picture:

  • Reorder Flags: parts that have hit their reorder point, with on-hand versus reorder level (shows the top 10; the header carries the full count).
  • Producible Units by Product: how many whole units each product can be built into right now, with the limiting (bottleneck) part named. Click a product to see what is short.
  • Recent Shipments, GRNs, Planned Issues, Ad Hoc Issues: the last few days of inward and issuing activity.
  • Returns by Channel: a 30-day bar chart of where returns came from.
  • Recent Activity: the last 10 system events, with a link to the full Activity Log.
⚠ “Producible” is the bottleneck count

The producible number for a product is how many whole units you can actually build given the part that runs out first, not a sum or an average. A green number means nothing is constraining it; red means the bottleneck part is short. The day-window panels (“last 7 days”) count back from the current time of day, so a record dated exactly 7 days ago can fall just outside.
