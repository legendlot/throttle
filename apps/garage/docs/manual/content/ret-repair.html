The Repair Pool is a worklist of returned units triaged to the workshop, grouped by variant. Use it to batch units into a scheduled repair run that the floor will work through.

What it’s for
Batching repair returns into a run.
Read or act?
Action: schedule a run.
Who
Store Admin
Fed by
Return triage (workshop).

Scheduling a repair run

  1. Select the variant buckets you want to repair (each row aggregates units of one product / model / colour; the count and oldest age are shown).
  2. Schedule Selected. A modal lets you set the quantity per variant (up to what is available), choose a repair line (L1, L2, L3) and add notes.
  3. Create Run. A repair run is created for the floor to work through; the store then issues the parts it needs.
ⓘ How units get here

Units land in this pool when they are triaged “Send to Workshop” during return processing. The screen aggregates by variant, so individual units are visible only through the sample UPCs on each row. After a run is created, the floor runs the repair-pass and repair-scrap steps at the scanner’s repair station.
