Ad Hoc Requests are one-off parts requests production raises when the floor runs short, outside any planned run. They are now raised in Redline (New Run / Request, Ad Hoc Parts tab); this Garage screen is where you track open requests and cancel them. The store issues them from the Issue Queue like any other request.

What it’s for
Tracking / cancelling ad hoc parts requests.
Read or act?
Track and cancel (raised in Redline).
Who
Production Admin
Then
Store issues from Issue Queue.

Tracking requests

The table lists each request with its status: Open (yellow), Pending Rework (blue), Cancelled / Rejected (red), Complete (green). Open or pending-rework requests can be cancelled here.

ⓘ Raised in Redline, by production

To create an ad hoc parts request, use Redline’s New Run / Request screen (Ad Hoc Parts tab). It is a production-only action, so the create form was removed from Garage; this keeps one place where production asks the store for material, runs and parts alike. There you can also link the request to a repair run so the parts are attributed to it.
