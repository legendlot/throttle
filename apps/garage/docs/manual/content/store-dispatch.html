Dispatch Activity is the same daily activity log as Manpower, but for the dispatch team on lines D1 and D2 (packing, returns, admin). It adds an Hours field so you can record time spent on each activity.

What it’s for
Logging dispatch-team activity and hours.
Read or act?
Action (supervisors).
Who
Store Admin
Roster from
Redline Daily Roster (D1/D2).

Using it

Pick the date. Each operator on D1 (pink) or D2 (cyan) gets a row. Set their Current Activity (Order Packing / Dispatch, Returns Processing, Admin / Other), enter the Hours spent (in quarter-hour steps), add notes, and save. The History button shows the day’s entries with hours per activity.

ⓘ Same model as Manpower

People come from Redline → Manpower → Daily Roster (the D1 / D2 buckets); Garage only logs activity. An activity must be set before notes or hours can be saved, and one Save covers both. The log is append-only. Editing needs floor-supervisor access.
