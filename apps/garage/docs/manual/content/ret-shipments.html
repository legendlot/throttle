Receive Return Shipments is the Returns landing page. Log a physical consignment of returned units as it arrives back from a sales channel, and see recent intakes. Open it the moment a return shipment lands at the dock.

What it’s for
Logging a return consignment in.
Read or act?
Action: creates a shipment.
Who
Store Admin
Then
Goes to Process.

Receiving a shipment

  1. Fill the form. Date received, the channel it came from (required), an optional platform reference (AWB), and units expected versus received.
  2. Receive Shipment. The consignment is created and you are taken straight into the Process screen for it.

The Recent Shipments list (filterable by date) shows each intake with its units (received / expected) and status: Open (yellow), Partially Processed (blue), Fully Processed or Handed Over (green), Closed (grey). Click any row or Process to work it.

ⓘ Units is received / expected

The units column is two numbers (received over expected), not a fraction; both default to zero. Creating a shipment jumps you into Process on purpose, so you can start logging units right away.
