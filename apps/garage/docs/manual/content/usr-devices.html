The phone fleet: every handset that has used the LOT Scanner app, plus every station slot in the register. Label a phone, pin it to a station, stop it scanning, or pair the attendance gate phone. Reached from Users & Roles → Phones.

⛔ This screen is no longer observe-only

Setting a handset to BLOCKED genuinely refuses it on every scanner action, within about 30 seconds. Earlier versions of this guide said nothing here blocked a phone — that stopped being true on 10 September 2026. The two flags further down are still observation only; blocking and locking are not.

⛔ Only the app appears here

A handset shows up the moment it uses the LOT Scanner app. A phone using the scanner website sends no device ID at all, so it is simply absent from this list, not shown and not flagged. That means an Unknown device almost always means “the app is not installed on this phone yet”, not “an unrecognised phone”. Until every scanner in the building is on the app, treat this screen as a rollout checklist, never as a security list.

The two flags

Two toggles sit at the top: Flag roaming devices and Flag unbound devices. Both start OFF, and each shows, live, how many devices it would catch right now if switched on.

⚠ Flags only, nothing is blocked

Turning a toggle on changes no floor behaviour today. It does not stop a scan, does not lock a device out, and does not need to be on for anything else on this screen to work. The count beside each toggle exists so nobody switches one on without first seeing what it would catch.

Roaming means a handset has been used to claim more than one station device code, for example the same phone used at both Store Issue and Returns Intake. Roaming is allowed; the flag exists to measure how often it actually happens before any rule is set on it.

Unbound means a handset has never claimed a station device code at all.

ⓘ Unbound is not suspicious

Attendance and Lookup are the two stations that never send a station code, so any phone used only for those legitimately shows as unbound forever. Do not read “unbound” as “unrecognised” or unauthorised; it is expected for those two stations and for any phone that has only just started using the app.

The table

Above the table, a row of coloured counts (Known, Unknown, Blocked) totals every device by status, and a search box filters the list by device ID, label, station code or IP as you type. Refresh re-reads the list from the worker.

Label at install time

ⓘ Label the phone while you are holding it

Label a device the moment the app is installed on it, while you are standing next to it and know exactly which station it belongs to. Come back to it later, once several unlabelled phones have appeared, and you are guessing between identical hardware IDs with no way to tell them apart.

Locking a phone to its station

Each phone card has a Lock toggle. Locked means the handset cannot be pointed at a different station from the phone itself — the station and line pickers grey out, and if someone has already moved it, it is moved back and told why.

⚠ Locking only works on the app, and only one station per handset

The lock is tied to the handset, not to the station code, because a phone’s station code is simply whatever its operator picked. A phone using the scanner website sends no handset ID and cannot be locked at all — each card says which of the two it is.

A handset can be locked to one station. If you try to lock a second station onto a phone that is already locked elsewhere, Garage refuses and names the other one: unlock that first. This is not a nicety — two locks on one handset would quietly stop both from working, and it could not be undone.

Pairing — one phone only

Only the attendance gate phone is ever paired; it is the only card that offers the button. Pairing mints a signing key, and that key is only ever checked when somebody clocks in or out, so pairing a station phone would create a key nothing looks at. Floor phones need no code at all: install the app, then department PIN → station → line, on the phone.
