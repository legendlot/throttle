The UDR Pool is a worklist of undamaged, re-sellable returns, grouped by variant, waiting to be handed back to production so they can re-enter dispatch stock. Use it to mark batches as issued to production.

What it’s for
Re-dispatching undamaged returns.
Read or act?
Action: mark issued.
Who
Store Admin
Fed by
Return triage (UDR).

Using it

Each row aggregates undamaged units of one product / model / colour, with a count, the oldest age, and sample UPCs. Mark Issued to Production hands the whole bucket back to production, which then re-packs each unit on the floor so it re-enters dispatch as a legitimate return.

⚠ It issues the whole bucket

“Mark Issued” is all-or-nothing per variant: it issues every unit in that bucket, with no partial-quantity option (unlike the Repair Pool). Units arrive here when triaged with disposition UDR during return processing.
