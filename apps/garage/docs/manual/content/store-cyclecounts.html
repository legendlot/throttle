Cycle Counts keep recorded stock honest against the shelf. The store picks which due parts to count, prints a sheet, enters counted quantities blind (the system figure is hidden until you enter yours), and on completion the system proposes stock adjustments for any variance.

What it’s for
Verifying shelf stock against the system.
Read or act?
Action (view open to all).
Who
Store Admin
Then
Proposes adjustments.

Running a count

  1. + New Count. The screen lists parts due (classed A / B / C by how much they move and cost). Pick the parts, name the area and counter, and create.
  2. Print the sheet and count the shelf.
  3. Enter each counted quantity and press Enter to save that line. The variance for that one line is then revealed.
  4. Complete the count once every line has a figure. The system proposes a stock adjustment for each variance.

If a line looks wrong you can flag it for recount (with a reason); a fresh recount is expected to be done by a different counter.

⚠ Blind counting, and completing only proposes

While a count is in progress the system quantity is hidden until you save your figure on that line; this is deliberate, to stop the count being biased. Completing a count does not change stock: it only proposes adjustments, which still need approval and posting on the Stock Adjustments screen. Watch the variance colours: over (counted more than the system) shows red, under shows yellow.
