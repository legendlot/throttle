Connects holds the conversations that Pitstop customer support has handed over to Ignition, usually creators who messaged the brand. From here you read the thread, reply, and turn a creator into an influencer record.

What it’s for
Replying to transferred creator chats.
Read or act?
Act: reply, link, set status.
Who
Marketer Lead Admin
Needs
The Connects permission.

The list

Each row is one conversation: who it is, the channel (Instagram, Messenger, WhatsApp or Email), the last message, how long ago, a status pill, and either the influencer code it is linked to or Not linked. An Awaiting reply tag marks threads where the customer spoke last. The search box filters the loaded conversations; every word must match. Filter by channel with the buttons and by status with the dropdown. The heading shows how many are New among the latest 200 conversations loaded.

Statuses

StatusMeaning
NewHanded over and nobody has dealt with it yet.
RepliedYou are working the conversation.
LinkedThe conversation has been tied to an influencer record.
ClosedFinished; nothing more to do.

Change a status from the dropdown in the Details card on the conversation. Linked cannot be picked by hand; it is set only by creating or linking an influencer (Promote, below), so the option stays greyed out until the thread has an influencer.

Working a conversation

  1. Read the thread. A thread shows its latest 500 messages, with times in IST; internal notes appear in a dashed box with the author’s name.
  2. Reply. Type in the box and press Send, or press Cmd+Enter (Ctrl+Enter on Windows). Plain Enter just adds a new line. Replies go out through Pitstop’s channel. On Instagram, Messenger and WhatsApp the box locks when the customer’s 24-hour reply window has closed; email has no such window.
  3. Link to an influencer. If the thread is not linked, Create influencer (Promote) first looks for an existing influencer with the same Instagram handle, phone number or email (archived ones are ignored). If one exists, the thread is linked to it and a toast says Linked to existing INxxx; otherwise a new record is made from the thread’s handle, phone or email. Once linked, the card shows the influencer code and a link to the profile.
  4. Hand it back if needed. Send back to Pitstop asks you to confirm, then returns the conversation to the support team’s inbox and removes it from Connects.
⚠ Check the code in the toast

Matching is by handle, phone or email, so a creator known under a different handle and number can still get a new record. Read the toast: “Linked to existing” means no duplicate was made.
