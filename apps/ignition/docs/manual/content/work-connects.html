Connects holds the conversations that Pitstop customer support has handed over to Ignition, usually creators who messaged the brand. From here you read the thread, reply, and turn a creator into an influencer record.

What it’s for
Replying to transferred creator chats.
Read or act?
Act: reply, link, set status.
Who
Marketer Lead Admin
Needs
The Connects permission.

The list

Each row is one conversation: who it is, the channel (Instagram, Messenger, WhatsApp or Email), the last message, how long ago, a status pill, and either the influencer code it is linked to or Not linked. An Awaiting reply tag marks threads where the customer spoke last. Filter by channel with the buttons and by status with the dropdown. The heading shows how many are New among the latest 200 conversations loaded.

Statuses

StatusMeaning
NewHanded over and nobody has dealt with it yet.
RepliedYou are working the conversation.
LinkedThe conversation has been tied to an influencer record.
ClosedFinished; nothing more to do.

Change a status from the dropdown in the Details card on the conversation.

Working a conversation

  1. Read the thread. Messages are shown with times in IST; internal notes appear in a dashed box with the author’s name.
  2. Reply. Type in the box and press Send, or press Cmd+Enter (Ctrl+Enter on Windows). Plain Enter just adds a new line. Replies go out through Pitstop’s channel. On Instagram, Messenger and WhatsApp the box locks when the customer’s 24-hour reply window has closed; email has no such window.
  3. Link to an influencer. If the thread is not linked, Create influencer makes a new influencer record from the thread’s handle, phone or email. It always creates a new record, it does not search for an existing one, so check Influencers first to avoid a duplicate. Once linked, the card shows the influencer code and a link to the profile.
  4. Hand it back if needed. Send back to Pitstop asks you to confirm, then returns the conversation to the support team’s inbox and removes it from Connects.
⚠ Create influencer always makes a new record

Pressing it for a creator who is already on the roster gives you a second copy. Search Influencers by handle first, and only create when they are genuinely new.
