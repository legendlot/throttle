Picking the product

Start typing in the Product box and pick from the list. Picking fills in both boxes — the product name in Product, the model and colour in Variant / colour — and pulls in the cost, so Goodies fills itself where we know what the item costs us. The selling price shows underneath with a use button, so you never have to go and look it up.

ⓘ Pick it rather than typing it

Typing a product name freehand still works, but a typed name is only text: no cost, no price, and it cannot point the tracking link at the right product page. Picking from the list is what connects the deal to the real product.

⚠ The wooden kits have no cost on record

Goodies will not fill itself for the Harry Potter crests or the other L.O.T Build items — we hold costs for only a few of them — so type the figure in. The selling price is still shown underneath to save you looking.

Creating a deal

  1. Find the influencer. Search by code, handle or name (type at least two characters) and pick from the results. Use Change to reselect.
  2. Set the deal terms. Engagement type (Video or UGC), deal type (Paid, Barter, Affiliate, Paid + Affiliate), payment terms and amount, the product code and variant, and where the deal drives traffic (Website, Amazon, Flipkart).
  3. Create Engagement. The deal is created at stage Identified and opens on its detail page.
ⓘ Only the influencer is required

You can create a deal with a ₹0 amount and a blank product and fill them in later; the only thing you must pick is the influencer. The search shows nothing until you have typed two characters, which is normal. Every new deal begins at the start of the pipeline and is advanced step by step afterwards.
