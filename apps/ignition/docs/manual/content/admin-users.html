User Roles explains how Ignition’s permissions work and where to manage them. Ignition does not manage accounts itself: it reuses the shared company roles, and assignment happens in Garage.

What it’s for
Explaining where roles are set.
Read or act?

Who

What it tells you

The page explains that Ignition uses the shared permission map, lists the five Ignition permissions (ignition_view, ignition_manage, ignition_approve, ignition_admin, ignition_reports_view), and notes the two bundled roles: ignition_manager (view, manage, reports) and ignition_lead (adds approve). Admins and super admins get everything automatically.

ⓘ There is no user table here

Despite the name, this screen has no “add user” controls. To actually change someone’s access, go to Garage → Users and set their role there; it then takes effect across Ignition.
