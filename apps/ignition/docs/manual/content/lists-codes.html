Discount Codes shows the pre-minted code pool and which codes have been used, on which order, and against which engagement. Open it to check code usage.

What it’s for
Seeing the code pool and usage.
Read or act?
Read-only.
Who
Marketer Lead Admin
Tabs
All · Unused · Used.

Reading it

Each row shows the code, its pool, whether it has been Used (green YES, else a dash), the order it was redeemed on, the order value, when it was used, and whether it is tied to an engagement. Filter with the All / Unused / Used tabs.

ⓘ Pre-minted, and view-only today

Codes are minted into the pool in advance, not created here; a code becomes “used” when a customer redeems it on an order, which fills in the order, value and engagement link. Bulk generation of codes is a later phase, so this screen is read-only for now. The list shows up to 200 codes.
