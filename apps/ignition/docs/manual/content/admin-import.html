Sheet Import documents how the legacy “Omnipresent” influencer spreadsheet is loaded into Ignition. It is a reference runbook for the technical team, not a button you click.

What it’s for
Documenting the data import.
Read or act?
Read-only (instructions).
Who
Admin (technical)
How
A command-line script.

What it explains

The page lays out the one-time migration steps: place the latest Omnipresent - Influencer.xlsx in Downloads, run the import script from the workspace, which posts the rows into the database through one-shot import routines. The import is idempotent (re-running it will not create duplicates), and the routines are removed afterward.

⚠ No upload button here

Despite the name, there is nothing to click on this screen: it is a runbook for an engineer doing a data migration from the command line. For day-to-day work you will never need it; influencers and engagements are added through the normal screens.
