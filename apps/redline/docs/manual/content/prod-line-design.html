Line Design defines the physical layout of each product’s assembly line: how many work stations sit in each department and how many people each holds. It’s the template that Line Setup staffs every morning. Designs are versioned, so layout changes are tracked over time.

What it’s for
Designing the station layout per product.
Read or act?
Action: create/edit/version designs.
Who
Admin / floor supervisors.
Feeds
Line Setup’s staffing.

The screen

On the left, the list of products that have a design, each with its active version (e.g. v3) and effective date. On the right, the editor for the selected product: a summary bar of worker totals per department, then the four department sections each holding station cards.

Departments are always Prep → Assembly → QC → Packaging, and stations are auto-coded PR-01, AS-02, QC-01, PK-03 by department and position.

Working with station cards

Capacity

Click the person icon to toggle a station between one worker (👤) and two (👤👤).

Car / Remote

Prep and Assembly stations can be tagged CAR (blue) or REM (purple) to mark which stream they handle. Click to tag, click again to clear.

Reorder / remove

Drag a card to reorder within its department; × removes it; the “+ Add station” tile adds one.

Creating and versioning

  1. + NEW creates the first design for a product. Pick the product, an effective-from date, optionally copy stations from another product’s design, and add notes.
  2. Edit, then SAVE CHANGES. The save button stays greyed out until you actually change something; nothing is saved until you click it.
  3. NEW VERSION when the layout genuinely changes. It carries the current stations forward as a starting point and requires a later effective date and a change note. The old version is kept in Version History, read-only.
ⓘ One design per product

A product can have only one line design. Once created it disappears from the New-design list; change it with SAVE CHANGES for small edits, or NEW VERSION when you want to preserve the old layout in history. To start a similar product, use the “copy stations from” option.
