Dispatch Counts runs a physical headcount of finished, dispatch-ready units. You snapshot every unit currently in a chosen status, print a checklist, the counter marks each present or missing, and on completion the system auto-raises stock adjustments for any discrepancy.

Running a count

  1. + New Unit Count. Pick the scope status (which units to verify, e.g. everything handed_over), name the area and counter, and create. Every matching unit is snapshotted into the count.
  2. Print the sheet and walk the staging area.
  3. Mark each unit present or missing; paste any UPCs found that were not on the sheet into the Extra box. Marks are staged as drafts, then saved with Apply Marks.
  4. Complete once nothing is pending. Missing and extra units automatically become stock adjustments, queued for L1 approval.
⚠ There is no list of counts

This screen does not show past counts. To reopen one, type its number (UCN-NNN) into the search box, so note the number when you create a count. Completing a count auto-raises adjustments for missing and extra units; those still need approving and posting on Garage’s Stock Adjustments screen.
