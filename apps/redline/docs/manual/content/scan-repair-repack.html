Three more Production categories handle units that are not fresh builds: Repair Run for units coming back for rework, Outsourced Run for finished units returned by a vendor, and Repack Run for swapping a packed unit’s channel. Each starts at its own first station and then rejoins the normal QC-to-PKG-Out line.

Repair Run

A repair run (REP-NNN) is a batch of returned units to be reworked. You select the run, then scan each unit in at the Repair station to start it. A returned unit is accepted only if the Store has issued it to this exact repair run (issued from the Returns Issue Repair pool). A unit issued to a different run, or not issued at all, is rejected. From there the unit goes through Workshop and QC like any other; on a QC Pass the car and remote are re-paired exactly as in fresh production.

Outsourced Run

An outsourced run (EXT-NNN) is one where raw materials were sent to a vendor who built and returned finished units. As the units come back, scan each one in at Ext Inwarding to bring it into the system against that run; it then flows through QC, Packaging and PKG Out like a fresh unit. Ext Inwarding checks that the scanned unit’s product matches the run, so a unit cannot be tagged to the wrong job.

Repack Run

A repack run swaps a packed unit from one channel to another. It is two stations:

  • Repack In. Select the run, then scan the unit’s box label (LOT-XXXXXXXX-E/R). It accepts a box label only, and only for a unit sitting at Dispatch In or Allocate (never a unit already shipped, and never a bare car or remote). Scanning it in releases the unit from any allocation and rolls it back so it can be re-boxed for the new channel.
  • Repack Out. Scan the unit and its destination box. Only a unit that was actually scanned in at Repack In is accepted, so a fresh unit cannot slip through here.
ⓘ Same handlers, different doorways

Repaired and outsourced units flow through the same QC, Packaging and PKG Out stations as fresh units; the categories are just separate doorways into one line. So a repaired or vendor-built unit is dispatched exactly like a freshly built one once it passes QC.
