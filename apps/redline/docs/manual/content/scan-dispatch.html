The Dispatch department’s Dispatch Flow category moves a finished unit out the door in floor order: Dispatch In, Allocate, Pack, then Dispatch Out. A separate Restock station pulls an unused unit back into stock. Dispatch stations bind to a dispatch line, D1 or D2.

Dispatch Flow · lines D1/D2.
Stations
Dispatch In → Allocate → Pack → Dispatch Out.

Dispatch Supervisor
You scan
Box labels (LOT-…-E/R) and box refs.

Dispatch In (DTK)

Takes a packed unit into the dispatch area. Scan the box label (LOT-XXXXXXXX-E/R). It accepts only a unit that has come through PKG Out (ready to dispatch); anything else is rejected.

Allocate (ALLOC)

Assigns a unit to a channel or shipment. Select the channel, then scan the box label. It accepts a unit at Dispatch In (first allocation) or one already Allocated (re-allocation is free), so you can move a unit between channels without a detour.

Pack (PACK)

Builds the physical shipment box. Select the shipment, then scan each unit’s batch label into it. The shipment dropdown shows all open shipments, not just today’s, so you can pack ahead for a future-dated shipment.

Dispatch Out (DOUT)

The final out-the-door scan. Scan the box label (BOX-XXXXX) or a batch label to ship it. After this the unit is shipped.

Restock

Returns an unused unit to stock (for example, a unit pulled from a box that was over-packed). Pick a reason, then scan the unit’s LOT UPC. Only unused units are accepted; this is not the path for a customer return.

⚠ A courier-touched return never goes through Restock

If a unit has been out to a customer and come back, it is a return, not a restock. Send it through Returns Intake in the Store department. Restock is only for unused units that never left.
