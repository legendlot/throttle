A template is the message itself. Campaigns and journeys both point at one rather than carrying their own copy, so a template is shared and editing it changes everything using it.

What it’s for
Writing the message, once, per channel.
Read or act?
Action screen.
Who
Author Manager
Versioned
Yes. Every save keeps the previous version.

Channels behave differently

Email

A subject line and a body, built in the visual canvas. No outside approval needed: write it and use it.

WhatsApp

Must be submitted to Meta and approved before it can be used for a broadcast. Approval takes time and can be refused. Plan for it.

SMS

The wording must be registered with the Indian DLT registry first (the one step outside Relay); then the editor’s Create at TrustSignal button pushes it to the sending vendor in one click. What goes out has to match the registered wording exactly.

RCS

Composed and submitted entirely in Relay — write it, press Submit to TrustSignal, and Sync pulls the approval. Every RCS template also names an SMS fallback template, because phones that can’t receive RCS get the SMS instead. Full walkthrough in the SMS & RCS chapter.

Variables

A variable is a placeholder filled in per recipient, like a first name or an order number. Every variable must resolve for that person, or the send is skipped rather than going out with a gap in it. Use the preview to confirm each one fills.

Duplicating instead of editing

Duplicate makes an independent copy. Reach for it constantly. Editing a template that a live journey or an approved campaign depends on changes what is already going out, with no review and no announcement.

⛔ Important

Never edit a template a live journey depends on. This has reached real customers before. Duplicate it, edit the copy, then repoint the journey deliberately.

Archiving

Archiving retires a template from the pickers so nobody wires it up again. Anything already using it keeps working, on purpose: silently breaking a live flow would be worse than letting an old template continue.

⚠ Watch out

Deleting a WhatsApp template on Meta’s side is not reversible from here and removes every language version at once. Archive in Relay instead unless you are certain.
