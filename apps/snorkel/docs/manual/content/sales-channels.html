Channels are the offline sales routes, General Trade, Modern Trade, and any others, and this screen defines them and, crucially, which dispatch channel each one hands off to. It is an admin setup screen you rarely need to touch.

The mapping

Each channel has a short key (GT, MT), a label, a dispatch channel it maps to, a sort order and an active flag. The dispatch-channel link is the important part: when an order on this channel is confirmed, the shipment that is created for the dispatch team is filed under the mapped dispatch channel.

Adding a channel

  1. Fill the Add channel row with a key, a label and the dispatch channel it should hand off to.
  2. Set a sort order to control where it appears in dropdowns.
  3. Add it. You can later change its dispatch mapping or toggle it active from the table.
⚠ Map every channel to a dispatch channel

A sales channel with no dispatch channel mapped has nowhere to send its shipments when an order is confirmed. Set the mapping before orders start flowing on a new channel.
