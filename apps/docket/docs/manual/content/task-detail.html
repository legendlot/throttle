Click a task anywhere in Docket and it opens in the task view: everything about that one task in a single place. By default it opens as a modal, a window over your list, and you can switch it to a side panel or a full page whenever you prefer. All three show the same task.

Modal, side panel, full page

Modal

The default. A centred window over a dimmed list. Click the dimmed area or press Esc to close it.

Side panel

A panel on the right while the list stays visible, scrollable and clickable behind it. Good for working down a list.

Full page

The task takes the whole screen inside Docket’s normal frame. The top-right button then reads Back to the list and returns you to the list with the task still open.

Switch with the Switch layout button in the task’s top bar (Open tasks as Modal, Side panel or Full page). Docket remembers your choice on this device. On a phone the task always fills the screen, with Details and Activity tabs at the top.

What’s on the task

The left side holds the task itself; the right side (or the Activity tab on a phone) holds the conversation.

SectionWhat it holds
Title and descriptionThe title (and, on a sub-task, a link up to its parent) and a free-text description. If you can edit the task, click either to change it.
Properties panelA tidy list of fields: Status, Owner, Collaborators, Deadline, Priority, Team, Program, Space, Created (and Completed once done). Click a value to change it. A recurring checklist item shows Repeats in place of Deadline.
Sub-tasksThe child tasks, with their own owners and statuses, and a done/total count.
DocumentsLinks to outside files (Drive, Sheets, anything with a web address). Docket stores the link, not the file.
ActivityTwo tabs: Comments, with a box at the bottom to write a comment, and History, the full audit trail.

Sub-tasks and Documents are sections you can fold shut by clicking their headings.

Editing

Every property is click-to-edit in the panel: click it, pick the new value, and it saves. The title and description save when you click away. You can only edit a task you own, created, or (as an admin) any task. Reviewers see all of this without the edit controls.

With focus outside a text box, these keys work inside an open task: Shift+S status, Shift+A owner, Shift+D deadline, Shift+P priority, s add a sub-task.

The deadline, and why it is locked

Under Deadline the panel shows the current date, and, once it has been moved, a REV tag with the number of revisions plus a line reading Original … · locked. The first date you set is the original promise and never changes. To move the deadline, open it and enter the new date and a required reason; the button reads Set the first time and Revise after that.

⛔ Abandoning is the only way to stop a task

There is no delete button anywhere in Docket. If a task should not be done, choose Abandon… (in the Status picker or the More actions menu) and give a reason; it is required and recorded. The task stays visible with a banner reading Abandoned and your reason. An abandoned task is read-only until it is reactivated: it cannot be edited, re-dated, re-parented, moved, commented on, or have collaborators or documents changed, and the server refuses any such change. The comment box is replaced by This task is abandoned — reactivate it to comment. You also cannot add a sub-task under it. Reactivating (a status change) is the one thing that works, and an admin can still delete a comment on it. The owner, creator or an admin can use the banner’s Reactivate button, which is also logged.

Comments and History

The Comments tab is a running discussion on the task. Type in the box at the bottom and press Comment; you can edit or delete your own comments. The History tab is the unchangeable record: every status change, every deadline revision (with its reason), every owner or priority change, every collaborator or document added or removed. You cannot edit history; that is the point of it.

✓ Share a task with a link

Use Copy link to send someone a direct link to the task; it opens on the full page. An address of the form /tasks?task=… opens the task over the Tasks list instead, which is also how Docket returns you to the list after you leave the full page. Either way the person only sees the task if they are allowed to see it.

ⓘ Moving a task to another space

The Space property lets the owner move a task into a different space, including a private one you belong to. Moving a task changes who can see it. Sub-tasks always follow their parent’s space.
