A Program is a simple label you put on tasks to group related work, “Diwali Launch”, “Warehouse Move”, “Q3 Hiring”. It is the lightweight way to tie scattered tasks together without changing who can see anything.

What it is
A soft, company-wide grouping label.
Affects access?
No. Purely a label.
Who can make one
Anyone, just by typing it.
Per task
Zero or one program.

Programs vs Spaces, the one thing to keep straight

Docket has two ways to organise, and people mix them up. The difference is access:

ProgramSpace

A Program just gathers tasks under a name. A Space walls tasks off. This chapter is Programs; the next is Spaces.

Creating a program

Use + New in the top bar and choose New program, or the + beside Programs in the sidebar. Type a name and create it. If a program with that name already exists (capitals do not matter), you are simply taken to it instead of making a duplicate. You can also create one on the spot from a task, as below.

Adding a program to a task

  1. Click the Program cell on a task row (turn the column on in Columns if you don’t see it), or the Program property in the task view.
  2. Pick an existing program from the list. In the task view you can also type a new name and press Enter to create it on the spot.
  3. To remove it, choose — No program — from the same dropdown.

Programs are shared across the whole company: a name you create is immediately available to everyone, and the list is case-insensitive, so “Diwali Launch” and “diwali launch” are treated as the same program rather than two.

Working by program

On the Tasks list, Program is a full citizen alongside Team:

  • Open a program from the sidebar to see all its tasks across every space you can access. Programs in the sidebar show a task count, and only programs you have visible tasks in are listed. List and Board views both work there.
  • Filter any list to a single program from the Filter panel.
  • Group by program to see the list reflow into one collapsible group per program.
ⓘ Program names are visible; the tasks underneath still aren’t

Because a program is just a shared label, its name is visible company-wide. But putting a program on a task in a private space does not reveal that task to anyone, the space's wall still holds. The label leaks the name, never the contents.
