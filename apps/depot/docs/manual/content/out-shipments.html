Shipments is the main dispatch workspace, where outbound orders are built and closed out. You create a shipment for a channel, set what it should contain (the manifest), open boxes and pack units into them, then mark it shipped. This is the one Dispatch screen where you do real work, not just watch.

What it’s for
Building & shipping outbound orders.

Finding a shipment

Status tabs across the top (All / Draft / Packing / Ready / Shipped / Cancelled) narrow the list. Next to them is a search box: type a shipment number, a title, or a channel name to filter the list as you type. Press / to jump into it. Clear the box to see everything again.

The shipment lifecycle

StatusMeaning
DraftCreated, manifest being set. Can be edited or deleted.
PackingBoxes open, units being packed. Can be edited or cancelled.
ReadyFully packed against the manifest, not yet shipped (a green Ready badge).
ShippedSent out: all its units marked shipped.
CancelledCalled off: its units return to the dispatch pool.

Building a shipment, step by step

  1. + New Shipment. Give it an optional title, pick a channel (required), set a scheduled date, and build the manifest: add each product and enter the quantity per model/colour variant. A live total shows at the bottom. Create it.
  2. Open the shipment (click its row). A drawer slides in from the right with meta cards (Channel, Pool/Target, Packed, Scheduled), the manifest with progress bars, and the boxes list.
  3. + Add Boxes. Open one or more packing boxes. Units get scanned into boxes on the floor; each box shows its unit count and status.
  4. Manage boxes as needed. Expand a box to see its units; Remove a unit (it returns to the pool), Reprint a label, Reopen a packed box, or Remove an empty box.
  5. Shipped. When everything’s packed, mark the shipment shipped; this updates every unit in it to Shipped.

Reading the numbers

Pool / Target

Units allocated to this shipment so far versus the manifest goal (e.g. 8 / 20). This is allocation progress, not the same as packed.

Packed

Units actually packed into boxes: green when 100% of a manifest line is packed, yellow while in progress.

Box status

Open (amber) being packed; Packed / Closed (green) done.

ⓘ Offline sales orders

A shipment created against an offline sales order carries an order tag and a delivery date field in its detail drawer. Set the date the goods reached the partner: Snorkel reads it to start the partner’s payment-due clock (45 days from delivery, falling back to the dispatch date if you leave it blank). For ordinary channel shipments this field does not appear.

⚠ Editing limits

You can only edit a shipment while it’s Draft or Packing, and you can’t set a manifest line below what’s already packed, nor remove a product that has packed units. Deleting is for drafts only.

⛔ Shipping is the commitment

Mark Shipped flips every unit in the shipment to Shipped; do it only when the consignment has genuinely left. Cancelling returns units to the dispatch pool (not lost), but “this cannot be undone”, so cancel deliberately.
