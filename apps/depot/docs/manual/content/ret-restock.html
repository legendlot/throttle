Unit Restock returns finished units that have already left the store back into sellable stock, so they can be dispatched again. When an order is cancelled, inventory comes back unsold, or a sample is returned, you paste the unit codes here and Depot puts each one back on the shelf, ready to re-pack and re-send.

What it’s for
Putting shipped units back into stock.
Read or act?
Action: returns units to stock.
Who
Operator Supervisor Admin
Tabs
Bulk Restock and Report.

Bulk Restock

  1. Pick a reason. Orders Cancelled, Unsold Inventory, Sample Return or Other. For Other a short note is required.
  2. Paste the unit codes. One per line, or comma or space separated. Duplicates are removed automatically. Up to 300 in one batch.
  3. Restock. Confirm the count. Each unit is flipped back to QC Pass and any remote paired with a car comes back with it.
  4. Read the result. A table lists every code as restocked (with the status it came from, plus the paired remote if there was one) or skipped (with the reason).

Why a unit might be skipped

Unknown
The code isn’t recognised, usually a typo. Check it and try again.
Already in stock
The unit is already back on the shelf, so there is nothing to do.
Use the returns or repair flow
The unit is in a state that restock won’t touch (for example a return being inspected, or in repair). Handle it through Returns instead.

Report

The Report tab is a read-only history of every restock. Filter by reason and date range, search by unit code, and see totals broken down by reason and by sales channel. CSV exports whatever the current filter shows.

⚠ Restock clears the unit’s packing

Restocking puts a unit back to a fresh, sellable state and removes it from any box it was packed in, so it must be packed again before it goes out. This is the desk equivalent of the scanner’s restock station and has the same effect, just done from a pasted list rather than scanning unit by unit.

ⓘ Re-sellable units only

Unit Restock is for units that are still good to sell: anything damaged, faulty or genuinely returned for inspection belongs in the Returns process, which decides whether each unit is re-dispatched, repaired or written off.
