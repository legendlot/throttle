Channel Master is the list of every dispatch and sales channel (Amazon, Flipkart, Cred, BOM Bulk, retail partners and so on) that shipments and units are assigned to. It is a small but important setup screen that defines the choices everywhere else in Depot. It is done-once setup, out of the daily flow.

What it’s for
Maintaining the channel list.
Read or act?
Action: add and edit channels.
Who
Supervisor Admin
No delete
Deactivate instead.

A channel’s settings

Name
The channel’s name (e.g. Amazon, Flipkart, BOM Bulk).
Type
Ecom, Retail or Other, shown as a colour badge across Depot.
Fulfilment model
Unit (dispatched per unit) or Bulk (warehouse transfer). Bulk channels make a “Destination Warehouse” field appear when you create a shipment for them.
Sale channel
Whether the channel generates revenue. This drives the green “sold” colouring and totals on the Dispatch Overview. Non-sale channels read as “Cost”.
Active
Whether the channel is offered when creating shipments. Inactive channels show dimmed.

Adding & editing

Add Channel opens an inline form; new channels are always created active. Edit on any row lets you change its name, type, fulfilment model, sale flag and active state. Each row also has an active toggle you can flip directly, without opening the edit form.

ⓘ Retire, don’t delete

There is no delete. A channel that is no longer used is switched to Inactive so its history stays intact and it simply stops appearing as a choice for new shipments.
