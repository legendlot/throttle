The Running Account is the single source of truth for who owes whom. It is the shared pool, shown as a ledger with a live balance. Exchange Rates is the reference rate Manifest uses; the actual bank rate is always set per payment.

Reading the running account

Net position

The headline balance. Positive means Solve Factory holds LOT’s money; negative means LOT owes SF.

Credits

LOT to SF wires paid in.

Debits

Goods, logistics charges and commission that SF has spent.

Ledger

Every entry in order, with a running balance. Click a row to see its detail and jump to the linked record.

Opening balance and any carried-forward adjustments from prior years sit in the ledger as their own entries, so the net always reconciles.

Exchange rates

Reference rate

Manifest pulls a daily CNY to INR rate automatically. It is shown in the top bar and on the Exchange Rates screen for reference.

Manual override

An LOT user with FX rights can set a manual rate for a date when needed.

Actual bank rate

The rate that matters for money is the one you enter on each vendor payment. The reference rate never overrides it.

⛔ Important

When you record a vendor payment, always enter the actual bank rate you paid at. The reference rate is only a guide.
