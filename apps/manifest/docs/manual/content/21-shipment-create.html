Creating a shipment

  1. New shipment. On the Shipments screen, click New shipment.
  2. Pick the mode. sea or air. The carrier list, date labels and the BL/AWB label all follow the mode.
  3. Choose the carrier. Pick the freight partner from the list (shown as code and company name). No carrier listed? Add it in Admin → Logistics partners.
  4. Enter the real dates. Loading date and Sailing date (for air, “Departure date”). These are the dates you actually know when booking.
  5. Add BL/AWB and container. The Bill of Lading or Air Waybill number, container type and number where known.
  6. Create shipment. Manifest opens the new shipment’s detail page.

How the dates pre-fill

From the sailing (or departure) date, Manifest suggests the downstream dates, arrival, customs clearance and delivery, using the timeline defaults for that mode. If you only enter a loading date, it works forward from there. These are suggestions, not locks: you can change any date afterwards on the detail page.

ⓘ Note

The timeline defaults (how many days each leg usually takes, per mode) are set by SF or Admin in Admin → Shipment timeline defaults. Tune them to match your real experience and every new shipment starts from sensible dates.

✓ Tip

You do not have to allocate items at creation. Create the shipment, then attach the orders it carries on the detail page (see Managing a Shipment).
