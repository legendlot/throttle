Users & roles

The Admin screen lists members grouped by organisation (Legend of Toys and Solve Factory) with their role and status.

  1. Onboard a Solve Factory owner. The SF owner first requests a login link on the sign-in screen (this creates their account). Then an admin adds them here and assigns the SF role.
  2. Assign or change a role. LOT finance / founder, SF owner, or admin. Roles control exactly what each person sees and can do.

Shipment timeline defaults

These are the day-offsets Manifest uses to pre-fill a new shipment’s expected dates, set separately for sea and air.

  1. Edit the offsets. For each mode, set how many days after the previous milestone each leg usually takes (loaded, sailing, docked, cleared, local transport, received).
  2. Save. New shipments now pre-fill from these. They are suggestions only; SF can change any date on a shipment.
ⓘ Note

These defaults are edited directly with no audit trail, on purpose; they are tuning knobs, not records. Adjust them whenever your real lead times change.

Logistics partners

The shared list of carriers and last-mile transporters (freight forwarders, shipping lines, couriers). Every carrier and last-mile picker in Manifest reads from this master.

  1. Add a partner. Click Add partner, enter the company, country and the modes it supports (sea, air, land), plus IATA or SCAC codes and a tracking URL where relevant.
  2. Create. Manifest assigns the partner code. It is now selectable everywhere.
⛔ Important

Partners are never typed as free text anywhere in Manifest. If a needed carrier or transporter is missing, add it here once. This keeps the master clean and the pickers reliable.

ⓘ Note

Vendors come from the shared LOT vendor master and already cover China, international and domestic suppliers, so there is nothing to set up here for vendors.
