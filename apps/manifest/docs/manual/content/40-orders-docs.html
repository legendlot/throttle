Finding an order

  1. Search. Type an order number or title in the search box; the list filters as you type and the dropdown jumps straight to a match.
  2. Read the columns. Order number, title, category, value, the Snorkel PO (if linked), state, balance due and date.
  3. Open it. Click any row to open its detail, where all the actions live.
State

Where the order is in its billing axis (in flight, delivered, partially invoiced, invoiced).

Balance

What is still due against the order, or paid when settled.

Documents

Every PI, invoice, bill of lading, packing list and wire receipt can be stored against its order or shipment. Filter by type, and download any file by a short-lived secure link.

Where files attach

From an order or shipment detail; the file is tagged to that record and a milestone is stamped for key types (like the PI).

Access

The vault is private. Downloads use a signed link that expires, so files are never publicly exposed.

✓ Tip

Attach the vendor PI and the bill of lading as you get them. They become part of the order’s timeline and make closing the order out clean and auditable.
