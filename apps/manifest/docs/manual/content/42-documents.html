Manifest can print two formal documents from an order: the China Purchase Order you send the vendor, and the GST tax invoice from Solve Factory. Both open as a clean printable page you save as a PDF, and you can reprint them as many times as you like.

Who
LOT Solve Factory Admin
Where
Order detail.
Output
Print, or Save as PDF.
Stored?
No. Reprint any time.

How it works

Open any order. In the header (and on the Invoiced card) you will find document buttons. Click one and a clean black-and-white document opens in a new tab and the print dialog appears on its own. From there choose your printer, or pick Save as PDF to keep a copy. Nothing is stored on the system: the document is built fresh from the latest order data each time, so it is always current and always available.

China PO

Available once an order has been placed (not while it is still a request or draft). It shows:

  • Buyer: Legend of Toys, with the company address and GSTIN.
  • Supplier: the Chinese vendor on the order.
  • Lines: vendor item code, description, quantity and unit price, in the order’s currency (RMB).
  • Totals: in RMB. No GST is shown, because purchases in RMB are not taxed here.

Click China PO in the order header to generate it.

SF Invoice (tax invoice)

Available once an order has been invoiced. The SF Invoice PDF button sits on the Invoiced card. It shows:

  • Seller: the Solve Factory billing entity on the invoice. Bill to: Legend of Toys with GSTIN.
  • Charges: goods value, shipping and customs (whichever apply), totalling the taxable value.
  • Tax: the GST amount on the goods, shown as a single IGST line.
  • Commission: the Solve Factory commission line (GST included).
  • Grand total and the amount written out in words.
ⓘ Note

The invoice is built from the order’s recorded totals, so it reflects whatever has been invoiced. If you reopen it later it will show the current figures. If you need a frozen copy of an invoice exactly as it was issued, save the PDF when you generate it.

ⓘ Note

If a button does nothing or shows an error, the order is not at the right stage yet (a China PO needs the order placed; an SF Invoice needs it invoiced), or your role does not include document access.
