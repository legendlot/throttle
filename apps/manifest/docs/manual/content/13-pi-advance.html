Once the PO is placed and sent, the vendor replies with a Proforma Invoice (PI). SF attaches it as evidence and then pays the vendor advance out of the shared pool.

PI

Attaching the vendor PI

  1. Open the order. Go to the order’s detail page.
  2. Upload the PI. Add the vendor’s Proforma Invoice as a document of type PI.
  3. It becomes a milestone. Manifest stamps a timestamped PI attached event on the order timeline, so everyone can see when it landed.
ⓘ Note

Manifest never generates the PI. It only stores the vendor’s, as evidence.

Paying the advance

  1. Open Vendor payment. On the order detail, click Record in the Vendor payment card.
  2. Choose the type. Set it to advance.
  3. Enter the amount. The amount in Yuan and the actual bank rate you paid at. Manifest shows the rupee value it will deduct.
  4. Record payment. The pool drops immediately by that amount.
⛔ Important

Always enter the actual bank rate you paid at, not the reference rate. The vendor advance is real money leaving the pool on LOT’s behalf.

✓ Tip

If recording the advance pushes the pool negative, Manifest nudges you to raise a draw-down so LOT can top the pool up. It is a prompt, not a block: SF can still pay from its own pocket.
