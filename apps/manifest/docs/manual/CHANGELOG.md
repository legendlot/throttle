# Changelog — Manifest Operations Manual

## 1.0.0 — 2026-06-17
First complete manual. Combined system + process guide, 18 chapters across five parts:
Getting Started (what Manifest is, signing in, who does what, the shared pool); The Order
Lifecycle (request → convert/place → PI & advance → produce/pickup & cancellation); Shipments
(air vs sea, create, manage, costs & last-mile); Money (payments & draw-downs, invoicing,
running account & FX); Workspace & Admin (orders/search/documents, users/timeline-defaults/
partners). Documents the payment-driven pool model, the vendor-code POs, and the parked Snorkel
projection. In-app System Manual tab + downloadable PDF.
