Departments define the CS teams (Inbound, Outbound, Confirmation, Messaging and so on) and which agent belongs to each. Departments control visibility: a non-admin only sees the tickets and calls in their own team.

What it’s for
Teams and who is in them.
Read or act?
Action: create, toggle, assign.
Who
Admin
Effect
Scopes everyone’s view.

Using it

The Departments table lists each team with its slug, name, sort order, agent count and an Active toggle. Add Department creates one (a URL-safe slug, a name, a sort order). The Agents table lists everyone with a per-row department dropdown: pick a team to move an agent into it (or “None” to remove them).

⚠ Changes apply instantly, no confirm

Toggling a department active and reassigning an agent both take effect the moment you click, with no confirmation, so a misclick is live immediately. Setting an agent to “None” drops their tickets and calls out of every department view. A slug is fixed once the department is created.
