WhatsApp Templates shows the pre-approved messages agents can send from the inbox. You do not create or edit templates on this page: they are made in Relay, and this page simply lists the ones that are ready to use.

Adding a template

The page opens with a short “To add a template” box and an Open Relay → Templates link (it opens Relay in a new tab). To add one:

  1. Open Relay → Templates and create a WhatsApp template on the Support WhatsApp account (WABA 1350960337019398), category Utility. A template on any other account cannot send from the support number.
  2. Give it a Meta name that starts with lot_support.
  3. Submit it to Meta. Once Meta approves it (and it is active), it shows up in the inbox’s WhatsApp Template button.
⛔ The name must start with lot_support

A template with any other name is treated as a journey template and will not appear here or in the inbox. Templates are no longer created on this page: the old editor saved drafts that were never registered with Meta, so they could never send.

Sendable now

Below the box, the heading Sendable now · N counts the approved lot_support templates agents can send today. Each one is a card showing its name, its Meta name (the exact name registered with WhatsApp) and its message wording. Nothing on these cards can be changed here.

If the list is empty it reads “No approved lot_support templates yet.” If it cannot load, a red error line appears instead of the count.

Template not showing?

Check in Relay that Meta has approved it, that it is active, and that its Meta name starts with lot_support. A template still waiting for Meta will not appear until approved.
